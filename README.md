# 🥬 FreshDoctor (프레시닥터)

> 농수산물 소매상을 위한 AI 기반 리스크 모니터링 · 발주 의사결정 보조 서비스

---

## 개요

농수산물 가격 변동, 기상 리스크, 수급 이슈를 통합 분석해  
소매상이 **"지금 뭘 해야 하는지"** 를 바로 판단할 수 있도록 돕는 웹 서비스입니다.

데이터는 있어도 흩어져 있고 해석하기 어렵다는 현장의 문제를 해결합니다.

---

## 핵심 기능

- **품목 리스크 모니터링** — 가격·기상·수급 데이터를 결합해 품목별 리스크 점수(0~100) 산출
- **이상 징후 알림** — 임계치 초과 시 대시보드 알림 발송
- **AI 행동 추천** — 규칙 기반 판단 + Claude API로 소매상 친화적 액션 문구 생성

---

## 기술 스택

| 영역 | 기술 |
|------|------|
| Backend | Spring Boot |
| Frontend | Thymeleaf |
| AI | Claude API + 규칙 기반 리스크 스코어 |
| Infra | AWS EC2 · Docker |

---

## 데이터 소스

| 출처 | 활용 |
|------|------|
| KAMIS API | 품목별 도소매 가격 |
| 기상청 API | 기온·강수·기상특보 |
| 농넷 / 공공데이터 | 수급일보, 작황 정보 |
| 네이버 뉴스 API | 이벤트 기반 리스크 조기 감지 |

---

## 리스크 점수 기준

| 구간 | 등급 |
|------|------|
| 0 ~ 29 | 안정 |
| 30 ~ 49 | 관심 |
| 50 ~ 69 | 주의 |
| 70 ~ 84 | 경계 |
| 85 ~ 100 | 심각 |
