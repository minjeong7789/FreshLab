# FreshDoctor (프레시닥터)

농수산물 소매상을 위한 AI 기반 리스크 감지·발주 의사결정 지원 웹 서비스

팀: **FreshLab (프레시랩)**

---

## 프로젝트 소개

농수산물 소매상은 가격표, 날씨, 산지 이슈를 각각 따로 확인해야 하는 정보 분산 구조 속에서 대부분 경험과 감으로 발주를 판단하고 있습니다. 문제의 본질은 데이터가 없는 것이 아니라, **의사결정 가능한 형태로 통합되지 않는다는 점**입니다.

FreshDoctor는 가격 · 기상 · 수급 · 뉴스 데이터를 통합 분석해 품목별 리스크를 점수화하고, 소매상이 바로 실행할 수 있는 행동 추천까지 제공하는 AI 보조 웹 서비스입니다.

## 핵심 문제와 해결 방식

| 문제 | 해결 |
|---|---|
| 가격·날씨·산지 이슈를 따로 확인 | 품목별 통합 대시보드 제공 |
| 정보를 사후에 인지 | 임계치 기반 사전 알림 |
| 데이터는 있지만 판단은 감에 의존 | 규칙 기반 리스크 점수 + AI 행동 추천 |

## 핵심 기능

- **품목 리스크 모니터링**: 관심 품목 등록 시 가격 · 기상 · 수급 데이터를 매일 갱신해 리스크 점수 산출
- **이상 징후 알림**: 임계치 초과 시 알림함(웹) 발송, 근거(가격 변화율 / 기상 위험 / 수급 이슈) 조회 가능
- **가격 예측 모델**: 단기 가격 변동을 증가 / 감소 / 유지 3단계로 예측
- **AI 행동 추천**: 규칙이 정한 판단(선발주 / 분할발주 / 대체품 검토 / 재고 점검)을 GPT API로 사람이 읽기 좋은 문장으로 변환

## 리스크 점수 (100점 만점)

| 요소 | 배점 |
|---|---|
| 가격 급등도 | 30 |
| 변동성 확대 | 17 |
| 평년 대비 괴리 | 15 |
| 기상 위험도 | 20 |
| 수급 / 작황 이슈 | 10~18 |

**점수 구간**: 0~29 안정 · 30~49 관심 · 50~69 주의 · 70~84 경계 · 85~100 심각

품목마다 기상 민감도가 다르기 때문에(예: 배추는 폭우·저온·한파, 사과는 냉해·우박·강풍), 품목-기상 민감도 테이블을 반영해 같은 기상 조건도 품목별로 다르게 채점합니다.

## 서비스 흐름

```
데이터 수집 (KAMIS / 기상청 / 뉴스 / 공공데이터)
  → 품목 표준화·정제
  → 가격·기상·수급 피처 생성
  → 규칙 기반 리스크 점수 산출
  → 경보 등급 판정
  → GPT API로 설명·행동 추천 문장 생성
  → 대시보드 / 알림함으로 제공
```

## 기술 스택

| 영역 | 기술 |
|---|---|
| 백엔드 | Spring Boot 3.x (Java 17) |

| 데이터베이스 | MySQL |
| AI | GPT API + 규칙 기반 리스크 스코어 엔진 |
| 인프라 | AWS EC2 + Docker |

## 데이터 소스

| 소스 | 방식 | 역할 |
|---|---|---|
| KAMIS Open API | 공식 API | 품목별 도소매 가격, 가격 상승률·변동성 계산 |
| 기상청 단기예보 API | 공식 API | 기온·강수·폭염·한파·태풍, 산지 기상 리스크 판단 |
| 네이버 뉴스 API | API | "폭우", "냉해", "출하 감소" 등 키워드 기반 이벤트 조기 감지 |
| 공공데이터포털(농림축산식품) | Open API | 생산량, 재배면적, 출하량 |
| 농넷 | 크롤링/일부 API | 수급일보, 가격 변동 원인 설명 (보조) |

## MVP 핵심 화면

1. **대시보드** — 관심 품목 리스트, 오늘 리스크 점수, 상승/하락 방향, 주의 등급
2. **품목 상세** — 7일/30일 가격 추세, 평년 대비 차이, 기상 위험 요인, AI 추천 행동
3. **알림함** — 리스크 임계치 초과 시 발생하는 알림 목록

## 시작하기

### 요구 사항

- Java 17
- MySQL 8.x
- Gradle

### 환경 설정

`src/main/resources/application.yml`에 아래 항목을 설정합니다.

```yaml
spring:
  datasource:
    url: jdbc:mysql://localhost:3306/freshdoctor?useSSL=false&allowPublicKeyRetrieval=true&serverTimezone=Asia/Seoul&characterEncoding=UTF-8
    username: ${DB_USERNAME}
    password: ${DB_PASSWORD}
    driver-class-name: com.mysql.cj.jdbc.Driver

openai:
  api-key: ${OPENAI_API_KEY}
```

> MySQL 8 기본 인증 방식(`caching_sha2_password`) 때문에 `Public Key Retrieval is not allowed` 에러가 날 수 있습니다. `allowPublicKeyRetrieval=true` 옵션으로 해결됩니다.

API 키, DB 비밀번호 등 민감 정보는 커밋하지 않고 환경 변수 또는 `application-secret.yml`(`.gitignore` 처리)로 분리해 관리합니다.

### 실행

```bash
./gradlew bootRun
```
